统计口径与测试条件

本页仅使用本轮重新实测的数据；缺少完整 16 场景或结束标记的尝试不填成绩。AUTO 不入表。一次完整运行，未做光学帧率与画面目视验收。

双方使用相同 LVGL 9.5.0、15 ms 刷新周期、24 KiB 渲染任务栈、板级驱动参数和场景。RGB / DSI 开启 XIP。IO 参数按板型分别配置，同一块板双方保持一致，详见板卡说明。SRAM 输入 tile 为 50 个逻辑行，PSRAM 输入为全屏容量；全屏容量仍使用 PARTIAL 渲染。

原始 LVGL FPS 保留原统计。非空绘制率为 16 场景各自的非空绘制次数 / 秒取算术平均，acquire 和 flush 等待均计入，不等同于屏幕确认显示帧率。每轮像素量见场景表。

Present NONE 按输入数量选择 D1 同步提交、D2 后台提交；adapter NONE 均由 LVGL 任务提交。对照固定输入数量及内存域，调度差异属于实现差异。TE 仅作近似流水线对照，需同时查看 FB、tile、staging 与总内存。adapter 原生 PARTIAL 仅一块输入 tile，D2 对照填 —。

优先级修复仅在生产者会话切换时更新独立 copy worker 的继承值，不做逐帧调优、不固定为 7。测试运行源码独立冻结，不包含另一个窗口后续的 IDF 6.0 兼容修改。

发布分支另带 IDF 6.0 回调兼容：新增两个旧回调语义回归后，常规、ASan＋UBSan、TSan、LVGL 9.2 均 63/63；9.2 公开旋转另连续通过 30 次。使用本轮 SDK 和目标编译参数，S3 / S31 / P4 的现代扫描适配器目标文件与冻结版本逐字节一致。未运行 IDF 6.0 真机性能矩阵。
