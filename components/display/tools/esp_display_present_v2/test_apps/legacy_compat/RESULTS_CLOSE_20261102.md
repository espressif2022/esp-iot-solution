# 2026-11-02 兼容与内存收敛验收

本轮保留默认旧组件选择，不宣布整体迁移关闭。当前事实优先于早期逐轮记录。

## 已落实

- 门面使用固定逻辑尺寸的运行时旋转；支持单 FB 持久 DIRECT、FB 字节交换、精确有效容量和 SPI PSRAM 安全 staging。
- RGB 通过公开只读 IDF 查询获取驱动事实，旧应用调用不变。SDK 扩展可复现补丁见 `../driver_patches/README.md`，不是已发布上游接口。
- TE 的 V1 测量策略作为注入 gate，GPIO/定时器生命周期归平台装配，原生后端不依赖 V1。无法证明安全窗口则等待/超时。
- coverage 常见矩形不分配全屏位图；碎片化才惰性分配，分配失败不发布图像。1024×600 常见路径省去 75 KiB 位图，增加有界矩形元数据；规划仍保留最坏预算。
- 精确差集按矩形边界跳过连续像素，避免每个像素反复查矩形。

## 实板

身份重新读取：P4 `e8:f6:0a:e7:a7:8d`，S3 `90:e5:b1:d0:a9:d8`，S31 `30:ed:a0:f4:0b:34`。

P4/S3 六种 FB 模式及取消后重绘成功，用户确认两块 benchmark 画面正常。P4 的独立纯色及随后 GSP/LVGL 交接也由用户确认可见；板级参数为 GPIO26 背光、1000 Mbps，未证明单一参数就是原黑屏根因。

| 官方 LVGL benchmark，同轮配置 | V1 | V2 区间优化前 | V2 区间优化后 |
| --- | ---: | ---: | ---: |
| P4 1024×600 | 28 FPS | 17 FPS | 27 FPS |
| S3 480×480 | 19 FPS | 11 FPS | 17 FPS |
| S31 GRAM 480×480，早期循环 | 25 FPS | 25 FPS | 未按此循环复测 |

以上是本轮特定 16 场景、50 行双 tile、同 LVGL 配置数据；不能直接替代历史其他配置的 42/41 FPS。P4 优化后实际 DMA2D 尝试 21246 次，CPU 回退 0；S3 仅 CPU 尝试 8629 次。尝试次数不等于成功 DMA 次数。

S31 早期 GRAM benchmark 有 IDLE0 watchdog 告警。测试循环对两实现同时改为最少阻塞 1 tick 后，V1/V2 均为 25 FPS，整段无 watchdog 告警；未关闭或放宽 watchdog。

S31 初轮重复 staging 测得发送约 35.4 ms，超过安全窗口，后续 begin 超时。新增公开 SPI IO 只读配置查询后，驱动明确开启 direct-PSRAM 的实例不再 staging；单 compose 0°、双 compose 90°及各自取消后重绘均通过，各 12 帧。测量策略日志给出 slow/end 窗口 `[0, 约 9930] µs`；该日志中的 `Ttx=23040 µs` 是准入估计，不能当成单独测得的 DMA 时长。后续 GRAM benchmark 25 FPS、无 watchdog。这里验收传输/生命周期和策略接入，不宣称穷尽光学无撕裂。未知 IO/未修补 SDK 仍 staging，无法证明窗口时仍超时。

GSP 1.5.1 实际链接、原 V1 运行基线通过。V2 初次启动 INVALID_ARG，诊断确认其默认 max_damage_areas=128，被门面固定 32 上限误拒绝。修复为验证所有区域，超出核心提示容量时要求真实全绘；成功提交仍是覆盖证明来源。128 区域尾项非法/后续帧/提交校验均加入 Host 回归。修复后 P4 启动四场景成功，用户确认完整界面正常可见，并实际记录触摸场景切换。

## 无效数据与证据口径

首个测试程序漏开性能采样，summary 无有效场景，已修正，不能用于跑分。第二个对照误传空 commit，V1 正确拒绝；已改明确 FULL 覆盖后重新对照。早期 SCENE 行是内部累加值而非场景平均；BENCH_DONE 使用 LVGL 汇总平均值，后续源码已修正 SCENE 归一化。

S31 ROM no-stub 写入曾中断，已改 stub 完整恢复并独立校验。所有测试均使用备份，恢复/校验以每轮 restore-verify 日志为准，不凭程序 finally 存在就宣布恢复成功。

原始日志、配置和 SHA 清单见 `evidence/20261102-close/`。其中固件清单为最新构建快照，P4/S3 V2 对应区间优化轮，不是优化前那轮；旧轮运行日志自身记录 app ELF 摘要。当前源码后的格式/诊断改动不等于旧实测固件逐字节一致。

## 保持的边界

连续无 bounce 的 S3 多 FB 和 refresh-on-demand 尚无安全退休适配，继续拒绝。未触发真实 underrun/丢失 EOF；Host 故障注入不等于该物理验证。未切默认依赖；TE 与 GSP 本轮复现的差异已按上述范围关闭。默认仍保持旧组件，后续是否切换应单独评审明确拒绝域和 S3 剩余性能差距。

重复回归曾发现 DIRECT 测试在 1 ms 超时预算下强制要求异步 acquire 立即成功，已改为仅对明确 TIMEOUT 有界重试；源像素保持和 dirty 覆盖断言不放宽。

最终恢复：P4、S3、S31 原 16 MiB Flash 均完成恢复及独立 digest 校验。SDK 补丁未提交；默认示例依赖未切换。
