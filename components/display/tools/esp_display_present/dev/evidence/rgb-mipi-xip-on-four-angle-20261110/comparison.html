数据口径与检测边界干净驱动成绩 / 独立诊断

正式帧率和内存取干净 IDF 轮，交接检测取独立轻量诊断轮，不混用成绩。每项完整 16 场景并成功关闭；仅 XIP ON，排除 NONE，adapter 不支持的 AUTO 记“−”。本轮全部四角度重新完整运行，未用历史 0° 或 XIP OFF 成绩补表。

内存仅展示四个剩余值：打开前、打开后、运行最小、关闭后。单位 KiB，剩余越多越好；present 的箭头表示相对 adapter 的差值。运行最小取该项局部低水位，内部 RAM 与 PSRAM 的最低点不一定同时发生。它不是“已用内存”，也不是 ELF 静态段统计。

S3 使用实际 bounce 源；S31 使用 AXI 预取描述符所属 FB；P4 使用实际装载 DMA 帧的独立快照。后两者不等于逐像素扫描证据。地址命中按检查点累计，同次提前交接可产生多条记录，不等于多次独立撕裂；零命中只描述已覆盖检查点。unknown 单列，不算正常。

adapter 的 0° 双缓冲 FULL/DIRECT 检查独立确认等待；旋转及其他模式检查 pipeline 交还，不适用项明确标出。诊断窗口不含 open/close，丢弃入口首半帧，但包含结束统计日志。S3 供数不足/既有重启与其他板硬件 underrun 分别计数。只检测、记录，没有修复、assert 或故障注入。

绿色箭头：present 帧率或剩余内存更高；红色箭头：更低。供数不足、地址交接命中和 unknown 独立解释，详见各板诊断及原始证据。
