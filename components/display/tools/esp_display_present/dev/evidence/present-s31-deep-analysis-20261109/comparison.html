这轮确认了什么

综合整数分相同不等于逐场景性能相同。原旋转缓冲容量并不相等，LVGL FPS 包含空刷新，原 CPU 100% 没有有效 idle 统计。present 借用缓冲后仍保留额外像素存储：S31 0° FULL/DIRECT 约多一屏 750KiB，旋转后需区分逻辑画布及 binding 保底。

XIP 改变外部代码和只读数据的访问路径；状态机与任务交接仍存在。下面使用非空绘制和每帧停顿量核对，不能把硬件 miss 寄存器当作缺失次数或 miss 率。
