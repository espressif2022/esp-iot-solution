预检发现并修复 quiesce 与 LVGL 绑定的兼容差异：渲染暂停且无 active frame/cancel 时可保留绑定排空；有真实延迟访问则超时后保留资源，完成后重试成功。对应 Host／ASan 回归均通过。未修改后端退休证据或缓冲拓扑。
